This is the source of truth for SRS: goals, rules, protocol and roadmap. The
chapters are Markdown files, and the same set renders to a PDF from
`index.typ`. Use the sidebar to browse a part, or press `/` (or `⌘K`) to search
every chapter title and summary.

## How to read

- **Deciding on SRS** — start with [Why SRS](/why), then
  [Introduction](/introduction) for the shape of the system.
- **Understanding the design** — Part II covers how schema becomes an API;
  Part III explains how it stays secure without TLS.
- **Building or contributing** — Part IV is the order of work, and Part V holds
  the rules, repository layout and current status.
- **Looking something up** — Part VI is the reference: schema keywords, data
  model, API routes, deployment, development commands, console and brand.

Every chapter begins with a status marker so you know whether the code follows
it. Where code and this book disagree, the book describes the intended
behaviour and the difference is listed under
[Status and verification](/status).
